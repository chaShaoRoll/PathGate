# PathGate

PathGate（路径之门）是一个面向 VS Code 工作区的文件与文件夹快捷入口管理扩展。它在侧边栏和底部 Panel 同时提供快捷视图，让你无需打断当前工作流即可访问常用资源。

## 主要功能

- 创建、重命名、排序和清理快捷分组。
- 通过文件选择器、当前编辑器或 Explorer 拖放添加文件和文件夹。
- 为快捷项设置别名、搜索、筛选和置顶。
- 在分组内排序快捷项，或在分组之间移动快捷项。
- 保留暂时失效的路径，并支持重新定位。
- 将文件快捷项从 PathGate 拖入编辑区打开。
- 导出快捷配置，并安全合并导入其他工作区。
- 侧边栏和底部 Panel 共享快捷数据，同时保留各自的搜索、筛选和展开状态。

## 快速开始

1. 在 VS Code 中打开一个文件夹或工作区。
2. 从 Activity Bar 打开“路径之门”，或显示底部 PathGate Panel。
3. 创建分组，然后通过标题栏操作、当前编辑器或拖放添加常用文件和文件夹。

## 数据与安全

PathGate 将快捷配置保存在当前 VS Code 工作区的扩展存储中，不会在项目内创建配置文件。普通快捷操作不会创建、重命名、移动、复制或删除快捷项指向的真实文件，也不会发起网络请求。

只有在你主动执行“导出快捷项…”并在系统保存对话框中确认位置后，PathGate 才会写入所选的 JSON 文件；导入操作只读取你选择的 JSON，并更新当前工作区的快捷配置。

## 系统要求

- VS Code 1.95 或更高版本。
- 桌面版 VS Code。
